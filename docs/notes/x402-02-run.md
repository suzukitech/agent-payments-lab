注記
- 初版（資産ガードなし）の実測は `x402-02-run-before-guard.md` に残してある。a/b/b'/c/d は今回取り直した。
- 下の e と e-2 は取り直せない（同じ現象を意図して再現できない）。**タグより前の版（`payment headers:` 行なし）で取得**したものを、そのまま載せる。f（公開 URL）も初版で取得（資産ガード追加前）。

## 実行台帳（20 USDC の入金から現在残高まで）
