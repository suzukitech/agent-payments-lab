## 詰まったこと

実行時エラーは無し。両ツールとも初回で成功した。ビルド時に1件だけ出た型エラー（paid-mcp）:

```
src/server.ts(24,5): error TS2769: No overload matches this call.
  Overload 1 of 6, '(name: string, description: string, cb: (extra: ...) => ...): RegisteredTool', gave the following error.
    Argument of type 'MCPToolCallback<...>' is not assignable to parameter of type '(extra: ...) => ...'.
      Target signature provides too few arguments. Expected 2 or more, but got 1.
```

- 原因: 引数なしのツールを `s.tool(name, description, paid(handler))` と書いた。`paid()` が返すのは `(args, extra)` を取るコールバックで、引数スキーマ無しのオーバーロード（`extra` だけ取る）と合わない。
- 直し方: 空のスキーマ `{}` を挟んで `s.tool(name, description, {}, paid(handler))`。README の Quick Start も `{ ticker: z.string() }` を挟む形。
- 補足: pnpm の `minimumReleaseAge` では詰まらなかった（`@modelcontextprotocol/sdk@1.32.1` は公開 2026-10-05 で十分古く、`pnpm-workspace.yaml` は変更なし）。zod は `@x402/mcp` の `^3.24.2` と SDK の peer `^3.25 || ^4.0` を満たす 3.25.76 に固定。
