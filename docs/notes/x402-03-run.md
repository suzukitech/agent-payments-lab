## N. 第3ラウンドで予想外だったこと

1. **fail-open は確かに払えた**。壊れた台帳で 3 回中 2 回支払いが成立し、1 回は未解明の `HTTP 402: {}` で未決済（この 402 は修正前後と無関係に時々出る）
